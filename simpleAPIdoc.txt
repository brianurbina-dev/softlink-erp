Simple API
Simple API es una solución realizada en C# que consta de una completa biblioteca de clases que permiten realizar todas las operaciones necesarias para la generación, timbre, firma y envío de DTE al Servicio de Impuestos Internos.

Cuenta además con otras 4 APIs que permiten realizar operaciones mediante scraping en el sitio del SII, como lo es la boleta de honorarios, gestión de folios CAF, mapas y el Registro de Compras y Ventas.

Puede ser consumida desde cualquier lenguaje que soporte peticiones HTTP.

No se conecta a servicios de terceros ni guarda información de terceros.

Permite generar todos los documentos electrónicos disponibles en el SII y actuar en ambiente de certificación o de producción.

Todos los endpoints requieren autenticación mediante una Api Key. Puede conseguir uno gratuitamente en www.simpleapi.cl

Limites de uso (RateLimit)
API SimpleAPI DTE

Límite por segundo: Hasta 3 consultas.

Límite por minuto: Hasta 40 consultas.

APIs de RCV, Boletas de Honorarios, Folios y Mapas

Límite por segundo: 1 consulta.

Límite por minuto: 5 consultas.

Limite por hora: 100 consultas.

Instrucciones de Autenticación
Todas las llamadas a SimpleAPI (DTE, RCV, Boleta de Honorarios, Folios y Mapas) requieren autenticación mediante una Api Key.

Api Key: La autenticación se realiza a través de un encabezado en la solicitud HTTP. Debes incluir la Api Key en el encabezado con el formato especificado a continuación:

Key: Authorization

Value: ApiKey

Bearer Token: Es un token que dura 24 horas y se puede obtener mediante endpoint en carpeta "Auth"-Obtener Bearer Token, con tu apikey.

Ejemplo en Python
A continuación, se muestra un ejemplo de cómo aplicar la autenticación en una solicitud utilizando Python y la librería requests:

python
Import requests
url = 'https://api.simpleapi.cl/{endpoint}'
headers = {
    'Authorization': '1111-1111-1111-1111'
}
Notas adicionales

Reemplaza 1111-1111-1111-1111 con tu Api Key real.

Asegúrate de que el endpoint de la URL esté correctamente definido para la solicitud que deseas realizar.

Consultar Estado DTE
https://api.simpleapi.cl/api/v1/consulta/dte
Encargado de consultar estados de envios, devolviendo una respuesta detallada en un archivo XML.

Descripción JSON
Certificado
Rut: Rut del certificado. Sin puntos con guión
Password: Password del certificado.
RutEmpresa: RUT de la empresa emisora del DTE. Sin puntos con guión.
RutReceptor: RUT de la empresa que recibe el DTE. Sin puntos con guión.
Folio: Folio del DTE a consultar.
Total: Total del DTE a consultar.
FechaDTE: (YYYY-MM-DD) Fecha del DTE a consultar.
Tipo: Código del tipo del DTE.
Ambiente: 0 para certificación. 1 para producción.
ServidorBoletaREST: true o false. Indica si la consulta se hará en los servidores de boleta del SII.
Posibles códigos de respuesta
DOK: Documento recibido por el SII. Datos coinciden con los registrados.
DNK: Documento recibido por el SII pero datos NO coinciden con los registrados.
FAU: Documento NO recibido por el SII.
FNA: Documento NO autorizado.
FAN: Documento anulado.
EMP: Empresa NO autorizada a emitir documentos tributarios electrónicos.
TMD: Existe nota de débito que modifica texto documento.
TMC: Existe nota de crédito que modifica texto documento.
MMD: Existe nota de débito que modifica montos documento.
MMC: Existe nota de crédito que modifica montos documento.
AND: Existe nota de débito que anula documento.
ANC: Existe nota de crédito que anula documento.

Consultar Recepcion DTE
https://api.simpleapi.cl/api/v1/consulta/recepcion
El endpoint "Consultar Recepción DTE" está diseñado para que los usuarios emisores de Documentos Tributarios Electrónicos (DTE) puedan verificar el estado de recepción de sus documentos por parte de los receptores.

Descripción JSON
Certificado
Rut: Rut del certificado. Sin puntos con guión.
Password: Password del certificado.
RutEmpresa: RUT de la empresa que emite el documento a consultar. Sin puntos con guión.
RutReceptor: RUT de la empresa receptora del documento a consultar. Sin puntos con guión.
Folio: Folio del DTE.
TipoDTE: Indica si el documento es 33: Factura Electrónica 34: Factura No Afecta o Exenta Electrónica 39: Boleta Electrónica 41: Boleta No Afecta o Exenta Electrónica 46: Factura de Compra Electrónica. 52: Guía de Despacho Electrónica 56: Nota de Débito Electrónica 61: Nota de Crédito Electrónica 110: Factura de Exportación. 111: Nota de Débito de Exportación. 112: Nota de Crédito de Exportación
Ambiente: 0: Ambiente de Certificación, 1: Ambiente de Producción.
Descripción Campos Response
isRecibido: Indica si el DTE ha sido recibido por el receptor. Un valor true significa que el documento ha sido recibido.

isAceptado: Indica si el DTE ha sido aceptado por el receptor. Un valor true significa que el documento ha sido aceptado.

isRechazado: Indica si el DTE ha sido rechazado por el receptor. Un valor true significa que el documento ha sido rechazado.

fechaEvento: La fecha y hora en que ocurrió el último evento relacionado con el DTE, en formato ISO 8601.

descripcion: Proporciona una descripción textual del estado actual del DTE. Por ejemplo, podria indicar que el documento no presenta eventos adicionales de reclamos o acuse de recibo.

Ventas por Mes
https://servicios.simpleapi.cl/api/RCV/ventas/01/2026
Generación de listado de Registros de Ventas por Mes.

Consideraciones sobre el SII (Detalle Boletas Electrónicas)
El SII solo permite generar un archivo de detalle de boletas por día y por contribuyente.

Si solicitas boletas a las 08:00 y existen, por ejemplo, 20 boletas emitidas en el mes, el CSV contendrá esas 20.

Si vuelves a solicitar el mismo detalle a las 12:00 del mismo día, el SII entregará exactamente el mismo archivo (20 registros), aunque se hayan emitido nuevas boletas después de la primera descarga.

El archivo se regenera recién al día siguiente (o cuando se haga la primera solicitud de ese día).

Descripción JSON de entrada
RutCertificado: Rut del certificado digital. Sin puntos con guión.

Password: Password del certificado.

RutEmpresa: Rut de la empresa de la cual se solicitará el registro de ventas. Sin puntos con guión.

Ambiente: 1 para producción. 0 para certificación.

ProcesaBoletas: (boolean)(Opcional)(defecto: false)true: la API incluirá en la respuesta el detalle de boletas electrónicas (DTE 39 y 41). false (o ausente): la API se comporta como hasta ahora; solo procesa facturas, notas de crédito/débito.

Parámetros de búsqueda:

Los Parámetros de búsqueda, deben ser indicados en el endpoint, de la siguiente manera: URL_BASE/api/RCV/ventas/MM/AAAA

Ejemplo:

https://servicios.simpleapi.cl/api/RCV/ventas/12/2021

Este endpoint solicitara al SII el listado de registros de ventas del mes Diciembre y año 2021.

Normalmente demora entre 40 a 120 segundos.
